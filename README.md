# QR Code Generator



Project Description



A simple QR Code Generator built using HTML, CSS, JavaScript and QRCode.js library.



Features



\- Generate QR Codes from text or URLs

\- Download generated QR Codes

\- Store QR History using Local Storage

\- Show QR Preview in History

\- Save Date and Time of generated QR Codes



\## Technologies Used



\- HTML

\- CSS

\- JavaScript

\- QRCode.js

\- Local Storage



How to Run



1\. Open the project in a browser.

2\. Enter any text or URL.

3\. Click on Generate QR.

4\. Download the generated QR Code.

5\. View previous QR Codes in the History section.
